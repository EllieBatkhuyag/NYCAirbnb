# 🗽 NYC Airbnb Explorer

Welcome to the NYC Airbnb Explorer — an interactive Shiny app designed to help users explore Airbnb listings across New York City. This tool allows users to filter listings by region, price, and property type, and also gives insight into local crime rates to help travelers make informed choices.

## 🚀 Features

- Interactive map of Airbnb listings by borough and neighborhood
- Filter listings by:
  - Price range
  - Room type
  - Availability
- View average rating, price trends, and number of reviews
- Compare crime rate data alongside listings for safety awareness
- Clean, modern UI powered by Shiny and ggplot2

- **R**: Data wrangling and visualization

- **ggplot2**: Data visualizations
- **Leaflet**: Interactive maps
- **dplyr / tidyr**: Data cleaning and manipulation
